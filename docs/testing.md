# 无真实账号如何测试

安装 `requirements-dev.txt` 后运行 `python -m pytest -q`。不需要 .env，不会验证真实账号或消耗模型额度。

`tests/conftest.py` 在应用导入之前设置假 Key、假工作空间与管理员配置。接口测试使用 FastAPI TestClient 和临时 SQLite，外部适配器由 fake 对象、monkeypatch 或 httpx.MockTransport 替换。模拟响应是测试输入，不是云端真实执行结果。

这些测试验证：身份隔离、消息处理及中断、文件状态机、SSE 事件处理、用量差值和扣费、欠费控制、独立定时会话、归档、自助接口、初始化重跑及网络结果不确定时避免重复创建。

例如初始化测试模拟“云端可能创建成功，但客户端超时”，检查再次运行只查询不重复 POST；随后模拟查到资源，检查 ID 正确写入临时配置。它能检测恢复逻辑错误，但不能证明当前账号有权限创建。

以下需要部署者使用真实账号按 [首次验收清单](prerequisites.md#5-首次验收清单) 联调：微信扫码、MA 权限/模型可用性、文件安全审核、图片理解、产物交付、云端访问后台的网络、当前平台计费字段。CI 不存储云凭证，也不执行这些操作。

新增测试必须继续隔离数据库和外部网络。不要在普通测试中调用真实微信或云端；mock 测试通过不能表述为真实端到端验证。
